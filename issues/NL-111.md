# NL-111: Gutscheincode wird nicht angenommen, wenn er kleingeschrieben eingegeben wird

- Gemeldet von: Kundenservice, Telefon-Team
- Datum: 15.09.2026
- Bereich: Warenkorb / Gutscheine
- Priorität: nicht gesetzt

Mehrere Anrufe zum Newsletter-Gutschein. Die Leute tippen "nordlicht10"
und bekommen "Gutschein ungültig". Wenn wir am Telefon sagen, sie
sollen es groß schreiben, geht es. Einer hatte auch ein Leerzeichen am
Ende vom Kopieren aus der Mail.

Im Newsletter steht der Code übrigens groß, aber das liest ja keiner so
genau.
